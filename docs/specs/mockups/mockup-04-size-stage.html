Size, stage, reconcile

Two inputs to a size · prepared not transmitted · verified after the fact

P1 sizing · P2 staging

Size comes from exactly two things: the entry reference and the invalidation. The order is prepared for you to submit — the system has no path to transmit. Afterwards it checks the broker rather than believing its own log.

PowerShell— tradesignals \ desk \ AVTX
┌─ SIZE ──────────────────────────────────────────────────────────────┐
  entry ref   14.62       side  BUY (declared)
  stop mode   vwap − 5c  cents · intraday default
  stop        14.33       below entry — correct side for a long
  risk/share  0.29
  risk        1.0R        regime grid →  HALF SIZE  → 0.5R applied
  size        862 sh
  other modes: percent · ATR fraction (swing) · manual price
└─────────────────────────────────────────────────────────────────────┘

┌─ STAGED ORDER ─────────────────────────── not transmitted ──────────┐
  BUY  862  AVTX  LMT 14.62          acct U1234567
  STP  862  AVTX      14.33          protective, attached

  well-formed yes   side declared yes   book validated yes
  transmit    false  — verified once, read back from IBKR
  expires     in 4:12 — nothing stays armed

   PRESS SUBMIT IN TWS   the system cannot send this. Only you can.
└─────────────────────────────────────────────────────────────────────┘

┌─ RECONCILE ─────────────────── IBKR · same-day, provisional ───────┐
  logged 3 trades   broker 3   symbol / side / qty match
  price differs on 1 — AVTX 14.624 vs 14.62 logged (flagged, not an error)
  authoritative pull runs next day after settlement
└─────────────────────────────────────────────────────────────────────┘

─ IF THE WALL EVER FAILS ─────────────────────────────────────────────

 FROZEN  An order was submitted that this system did not transmit.
        Order management is now READ-ONLY. Nothing further will stage.
        You may be long 862 AVTX in account U1234567. Consider flattening
        manually in TWS. This system cannot place that order for you.
        Re-arm: clear the breach in config, restart. There is no button.

Margin notes

1Side is stated, never inferred Sell reduces a long; short opens negative exposure. The system refuses to stage anything whose side it had to guess.
2Transmit is a missing capability Not a policy the code follows. The flag is hardcoded off, and TWS order presets sit behind it as a second wall you own.
3Verify once, then get out of the way The read-back runs at stage time only. After that a submitted order means you pressed the button, which is expected.
4A breach freezes, it doesn't fix Read-only means the flatten is a suggestion with symbol, quantity and account — not a prepared order.
5Believe the broker, not the log Quantity and side must match exactly. Price and fee differences are flagged separately rather than called errors.
Never naked Auto-cancel of a stop is legitimate only when the position is flat. Cancelling protection on a live position is a bug, and is handled like a breach.
